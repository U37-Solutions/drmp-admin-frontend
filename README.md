# DRMP — Адміністративна панель

Фронтенд адміністративної панелі для системи **DRMP**. Побудований на React 19, Vite та Ant Design; підтримує ролеву модель доступу, управління компаніями, офісами, користувачами, зворотним зв'язком та картами на основі власних тайлів.

---

## Стек технологій

| Категорія | Бібліотеки |
|-----------|-----------|
| **UI** | React 19, Ant Design 5, SCSS |
| **Маршрутизація** | TanStack Router (file-based, code splitting) |
| **Запити до API** | TanStack React Query + Axios |
| **Форми** | React Hook Form + Zod |
| **Карти** | MapLibre GL, react-map-gl, Nominatim (геокодинг) |
| **Стан** | Zustand |
| **Білд** | Vite 6, TypeScript 5.8 |

---

## Функціональність

- **Авторизація** — вхід, реєстрація, відновлення пароля, токен-запрошення
- **Компанії** — перегляд, верифікація, контактна інформація, вкладки з деталями
- **Офіси** — CRUD, прив'язка до карти, геолокація
- **Користувачі** — запрошення, ролі, профілі
- **Чати** — вбудований чат через WebSocket
- **Зворотний зв'язок** — перегляд та обробка фідбеку
- **Журнал змін** — changelog компаній
- **Редактор форм** — налаштування кастомних полів (доступно `_admin`)
- **Карти** — векторні тайли (Україна), пошук адрес через Nominatim, вибір точки кліком

### Ролеві макети

| Роль | Доступ |
|------|--------|
| `_admin` | Редактор форм, повний доступ |
| `_editor` | Компанії, користувачі |
| `_companyAdmin` | Деталі своєї компанії, логи, користувачі |
| Авторизований | Профіль, офіси, чати, фідбек |

## Змінні середовища

Скопіюйте `.env.example` у `.env` та заповніть значення:

```env
VITE_API_URL=          # URL бекенд API (REST)
VITE_SOCKET_URL=       # URL WebSocket-сервера
VITE_TILES_URL=        # Базовий URL сервера векторних тайлів
VITE_NOMINATIM_URL=    # URL Nominatim для геокодингу (reverse geocoding)
```

> Якщо `VITE_TILES_URL` не вказано — картографічний компонент відображає повідомлення про відсутність конфігурації.

## Запуск

### Вимоги

- Node.js ≥ 18
- npm ≥ 8

### Встановлення та запуск

```bash
# 1. Встановити залежності
npm install

# 2. Налаштувати змінні середовища
cp .env.example .env
# відредагуйте .env

# 3. Запустити dev-сервер
npm run dev
```

### Інші команди

```bash
npm run build    # production-білд (tsc + vite)
npm run preview  # перегляд production-білду локально
npm run lint     # ESLint перевірка
```

## Карти

Картографічний шар базується на **MapLibre GL** з власним стилем (`mapStyle.ts`). Стиль включає:

- фон, воду, землекористування, дороги, будівлі, межі
- підписи населених пунктів та транспортних об'єктів

Геокодинг (пошук адреси та зворотне визначення координат) здійснюється через **Nominatim**-сумісний сервер, заданий у `VITE_NOMINATIM_URL`.
